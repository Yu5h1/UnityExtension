# Addressables 入門操作（Yu5h1LibTest）

在 Yu5h1LibTest 把一個新角色做成 Addressables 內容，從勾選到進 Play 看到它載入。環境：Unity 6000.6.0f1、Addressables 2.11.2，專案已經有 Addressables 設定與測試場景 `Assets/AddressablesTest/AddressablesTest.unity`。

## 1. 看懂 Groups 視窗

```text
Window → Asset Management → Addressables → Groups
↳ 展開 AddressablesTestCharacters → 看到 TestCharacter
```

這一列有三個欄位：

| 欄位 | 意思 |
|---|---|
| Group Name \ Addressable Name | 程式找它用的名字（address），這裡是 `characters/test-character` |
| Path | 資產在專案裡的位置 |
| Labels | 分類標籤；這次不用 |

視窗上方工具列：`New`（新增 group）、`Profile`、`Tools`、`Play Mode Script`、`Build`。

## 2. 準備練習用的角色

```text
Project 視窗 → Assets/AddressablesTest/Content → 選 TestCharacter.prefab
↳ Ctrl+D 複製 → 重新命名為 TestCharacter2
```

不要勾 `Resources` 資料夾裡的角色：勾選時 Addressables 會把它搬出 Resources，Resources 讀取器的測試就找不到它。

## 3. 勾選 Addressable

```text
選 TestCharacter2.prefab → Inspector 最上方 → 勾選 Addressable
```

確認：

- 勾選框旁出現 address 欄位，內容是資產路徑
- Groups 視窗的 `Default Local Group` 多了 TestCharacter2

## 4. 命名 address

```text
Inspector 的 address 欄位 → 改成 characters/test-character-2 → Enter
```

也可以在 Groups 視窗雙擊該列的名字修改。程式用 `Prepare("characters/test-character-2")` 找它，大小寫與斜線都要一致。

## 5. 放進 group

```text
Groups 視窗 → 把 TestCharacter2 從 Default Local Group 拖到 AddressablesTestCharacters
```

確認：TestCharacter2 出現在 AddressablesTestCharacters 底下，`Default Local Group` 變回空的。

要自己建新 group 時：`New → Packed Assets` → 右鍵新 group → `Rename`。

## 6. 設定 Play Mode Script

```text
Groups 視窗工具列 → Play Mode Script → Use Existing Build (requires built groups)
```

`Use Asset Database (fastest)` 不讀建置好的內容，不能證明打包結果，驗收不用它。

## 7. 先不 Build 試一次

```text
開 Assets/AddressablesTest/AddressablesTest.unity → Hierarchy 選 CharacterAgent ↓
Inspector 的 Mono Event Handler → Start 事件裡 Prepare 的字串欄位，
改成 characters/test-character-2。
↳ 按 Play
```

確認：Game 視窗左上顯示「失敗（characters/test-character-2）」。新 address 還沒建置進內容，所以找不到。

停止 Play。

## 8. Build

```text
Groups 視窗工具列 → Build → New Build → Default Build Script
```

第一次建置可能跳出是否開啟 Debug Build Layout 的對話框：選哪個都可以，回答後建置才會繼續。

確認：Console 沒有紅字錯誤。

## 9. 進 Play 看結果

按 Play → 看 Game 視窗左上的文字

確認：

- 文字從「載入中」與百分比變成「成功（characters/test-character-2）」；本機讀取很快，百分比可能一閃就過
- 畫面中出現角色，Hierarchy 有 `TestCharacter2(Clone)`

停止 Play。

## 10. 還原

```text
CharacterAgent 的 Start 字串改回 characters/test-character → 存檔場景
```

不想留練習角色：刪掉 `TestCharacter2.prefab` → `Build → New Build → Default Build Script`。

## 之後要改內容時

改了 Addressables 裡的資產（換貼圖、改 prefab、新增 address）→ 重新 `Build → New Build → Default Build Script` → 再進 Play。

Use Existing Build 只讀上次建置的結果，沒重新建置就看不到修改。

## 目的

- 會用勾選、address、group、Play Mode Script、Build 把一個資產做成可依 key 載入的內容
- 知道沒建置時為什麼失敗、建置後怎麼確認成功
